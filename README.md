# AssetIQ

Industrial Predictive Maintenance Platform

AssetIQ is an end-to-end industrial machine learning
platform designed to detect abnormal equipment behavior
and investigate early warning opportunities using
multivariate industrial sensor data.

## Dataset

UCI MetroPT-3 Air Compressor Dataset

https://archive.ics.uci.edu/dataset/791/metropt%203%20dataset

DOI: 10.24432/C5VW3R

License: CC BY 4.0
